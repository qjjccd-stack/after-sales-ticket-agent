## 新用例覆盖的关键失败边界

- 三个账号同时竞争一个席位，只放行一个；同账号换会话也不能突破单账号并发限制。
- 一次准确用量只结算一次；重试使用累计 usage 的差值；重复结算无效。
- 超时、估算或未知用量保留预算；模拟进程崩溃后席位过期，预算不会被释放。
- 新应用实例沿用 SQLite 中的频率记录；UTC 跨日时恢复新一天额度。
- 配置金额上限时必须提供完整合法单价；金额、Token、频率、总开关分别能拒绝新的模型执行。
- 真实 HTTP/ASGI 链路完成登录、消息提交、LangGraph 工具提案、点击确认、重复确认、查询与新应用实例恢复；模型用固定脚本替代远程接口。
- 已完成请求返回缓存结果，不再扣额度；模型暂停不影响表单提案。
- 执行入口抛出异常时释放席位，同时保守保留未知用量预算。
- v3 表结构升级后原账号和会话保留；恢复时释放模型席位，保留预算。
- 备份失败不更新成功标记；旧标记超时后健康检查失败；独立子进程能按容器相同的模块入口运行。
- 重置密码及停用账号会撤销已有登录；不能停用最后一个有效管理员。
