## 本轮发现与修复

1. 首轮真实验收为 19/20。FAQ 无匹配时，LangGraph 返回 `ToolMessage(content=[])`，原脚本把空内容当 JSON 文本解析，触发 JSONDecodeError；页面也未准确展示空列表。新增共享解析函数并添加页面、验收脚本回归测试，最终真实用例 05 通过。
2. 逐条阅读发现模型会重复索要已知故障，或将 FAQ 步骤扩写进工单描述。提示词明确简短故障描述有效、只追问缺失字段、保留用户原话；最终用例 11 和 14 验证通过。
3. 最终样本仍有两处措辞可改进：03 的 FAQ 尾部有通用补资料提示；08 的聊天创建时间未写时区。均未改变建单参数、状态或数据库结果，下面保留备注，不声称回答措辞完全无误。
